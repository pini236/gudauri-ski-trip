בקנבס: עמוד "סבב 12: חשבון וקבוצה באתר" (https://claude.ai/artifact/TVdeDbFBhvFDZdhCKjcys4), עם כרטיס "מה לאשר".

## איך זה נבנה

המסכים מצוירים **בתוך האתר האמיתי**: התסריט טוען את `site/`, מוסיף את החלקים החדשים עם המחלקות והטוקנים של האתר, ומצלם. כך מה שמאשרים הוא מה שייבנה.

```
python3 -m http.server 4199 -d site &
node design/round12/proto.mjs design/round12/shots
python3 design/round12/build.py <תיקיית הקנבס>
```

- `proto.mjs`: מריץ את האתר בכרומיום ומצלם כל מסך. הגופנים נטענים מהעותקים שבאפליקציה, כי בסביבת הענן אין גישה לגוגל פונטס.
- `proto-lib.js`: המסכים עצמם. `proto.css`: רק מה שאין עדיין באתר; במימוש זה עובר ל-`site/css/site.css`.
- `build.py`: לוחות הקנבס, מהתמונות שהועלו לקנבס (הכתובות בקובץ).
