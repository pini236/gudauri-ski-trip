## למימוש (סשן המנהל, אחרי האישור)

- מפתח חדש `meta.site_name` (Gudi) ל-`og:site_name`; `common.site_name` נשאר לסרגל, עם שם המקום. `pv-brand` בדף הפרטיות לפי הסרגל.
- `site/og.jpg` מחדש מ-`og.py` (1200 על 630, JPEG, פחות מ-200KB), ו-`og:image:alt`. `design/og/og.html` יוצא משימוש.
- `run.share_title` → "{run} · גודאורי"; `meet.card_sub` → "גודאורי"; `about.pass_top` → "SKI PASS · Gudi". נשארים: `about.bio`, שם המשחק "הירידה של החבר׳ה", `group.create_name_ph`.
- לגוגל (עם הארכיטקט): `hreflang` לכל שפה עם `?lang=`, `canonical`, `og:locale:alternate`, `robots.txt`, `sitemap.xml`, ונתונים מובנים של `WebSite` עם `name: Gudi`.
- הסמל בלשונית ובגוגל (`site/favicon.svg`) הוא השלט הישן; כבר שאלה פתוחה ב-`docs/ROADMAP.md`. מומלץ להחליף לסמל של האפליקציה יחד עם הפתיחה.

## איך נבנה

```
python3 design/round27/og.py          # og-a (העולם של החנות), og-b (הנוף מהכפר), והריבועים
node design/round27/mocks.mjs         # תצוגת גוגל ווואטסאפ מ-copy.json
node design/round27/shots.mjs         # הסרגל במחשב מעל האתר האמיתי (השרת על 4199)
python3 design/round27/build.py webp  # ואחרי העלאה לקנבס: python3 design/round27/build.py
```

התצוגות של גוגל ושל וואטסאפ מצוירות קרוב ככל האפשר למה שהן מציגות (גדלים, צבעים וגופן), אבל אינן צילום של השירותים עצמם. `og.py` דורש `numpy` (בשביל `design/round9/build5.py`).
