# סבב 14: ניהול הקבוצה באתר

לבקשת פיני (2.10.2026: "תתחיל עם ניהול הקבוצה בקנבס, ותעשה הכל"). בקנבס: עמוד "סבב 14: ניהול הקבוצה באתר". המסכים מצולמים מהאתר עצמו, מהענף `claude/site-group-admin`, **שלא ימוזג עד אישור של פיני** (החלטה 18).

- **ניהול הקבוצה למנהל** (כמו `Q10` באפליקציה): תפריט ⋮ לכל חבר (מינוי למנהל או הורדה, מילוי הטיסה בשבילו, הוצאה בלחיצה שנייה), ושלוש שורות: שם ותאריכים, הגדרות ההזמנה (אישור מנהל, קוד וקישור חדשים, ביטול), מחיקת הקבוצה בלחיצה שנייה. בטלפון ובמחשב.
- **שיאים מהמשחקים באתר:** `site/js/telemetry.js` שומר בדפדפן את השיא לכל משחק מאירוע `game_end` (בלי לגעת בקבצי המשחקים), ו-`site/js/account.js` שולח אותו לקבוצה (`submit_score`) רק אחרי הצטרפות. בבית הספר לסקי: סך הכוכבים (הטוב בכל שיעור); בשאר: הניקוד הכי גבוה. האפליקציה צריכה לספור אותו דבר.
- **מפגש לקבוצה הנכונה:** מי שבכמה קבוצות בוחר.
- **באתר עכשיו:** סבב 12 כפי שנבנה, לסגירת המעגל.

`shots.mjs` מצלם (שרת מדומה, שמות מומצאים; `ONLY=<regex>`), ו-`build.py` בונה את הלוחות לקנבס.
