## איך מגיעים לצילומים

1. המבצע שולח מספר ריצה של `android-qa` (חלק `redesign`) ואת הקומיט.
2. בכלי GitHub: רשימת התוצרים של הריצה, והורדת התוצר `android-qa-redesign`.
3. לפתוח את הקובץ בתיקייה ריקה משלו; הצילומים ב-`shots/NN-redesign-*.png`, 1080 על 2400.
4. שלושה כלים קטנים ב-`design/redesign/tools/review/` (להריץ עם `python3 -I`, מתיקייה אחרת):

```
python3 -I design/redesign/tools/review/sheet.py <תיקיית הצילומים> <פלט.jpg> <שם קובץ> <שם קובץ> ...
python3 -I design/redesign/tools/review/crop.py <פלט.jpg> "<קובץ>@x0,y0,x1,y1" ...
python3 -I design/redesign/tools/review/contrast.py "<קובץ>@x0,y0,x1,y1" ...
```

הראשון מניח כמה צילומים זה ליד זה, השני חותך ומגדיל אזור, והשלישי מודד את בהירות הרקע באזור ואת הניגודיות של טקסט לבן וטקסט כהה מולו.
