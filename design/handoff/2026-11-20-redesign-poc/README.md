## התאמה למסך

התמונה בגודל קבוע, והלקוח ממלא בה את המסך בהגדלה אחת ובהזזה אחת, **אותן הגדלה והזזה גם לשכבה החיה**:

```
k = max(רוחב המסך / 390, גובה המסך / 844)      // ב-dp
הזזה: ממורכז לרוחב ולגובה
```

במבט הקרוב התמונה (390 על 560) צמודה לראש המסך, והגיליון מכסה את התחתית:

```
k = max(רוחב המסך / 390, (גובה המסך − גובה הגיליון + 12) / 560)
```

## ההטלה (לבדיקה, ולמיקום עצמי בעתיד)

ב-POC אין צורך להטיל כלום: כל הקווים כבר מוטלים בקובץ. הנוסחה כאן כדי לבדוק נקודה בעין.

```
e = (lon − lon0) · kx          n = (lat − lat0) · ky        // geo בקובץ: lat0 42.51, lon0 44.495, kx 82060.586, ky 111320
u = e − c[0]                   d = n − c[1] + near          // proj בקובץ, לכל מבט
x = W/2 + S · u
y = y_c − S · ( F(d) + (z − zref) · C(d) )
```

`F` ו-`C` הן טבלאות בצעדים של 10 מ׳ (`step`), עם אינטרפולציה ליניארית: `F(d)` הוא בין `F[d/10]` לבא אחריו. `z` הוא גובה הנקודה במטרים.

**נקודות לבדיקה** (`check` בקובץ, 12 נקודות; כאן חלק): קצוות של רכבלים, עם הגובה של המודל.

| נקודה | lat, lon, גובה | במבט הרחוק | במבט הקרוב |
|---|---|---|---|
| Goodaura, קצה תחתון | בקובץ, 2161.3 | 156.6, 641.3 | 269.1, 529.9 |
| Goodaura, קצה עליון | בקובץ, 2705.6 | 178.5, 418.1 | 311.8, 93.9 |
| Sadzele, קצה עליון | בקובץ, 3235.0 | 272.4, 232.6 | מחוץ לתמונה |
| Shino, קצה תחתון | בקובץ, 2172.7 | 58.7, 621.2 | 77.7, 490.6 |

בעין: תחנות הרכבלים (`lifts[].stations`) צריכות לשבת בדיוק על קצות הקווים האפורים שב-`ref/hero-day.jpg`.

**המבט הקרוב הוא הרחוק, מוגדל:** לכל נקודה של מסלול שבתוך המבט הקרוב,

```
x_קרוב = x_רחוק · 1.95313 − 36.9          y_קרוב = y_רחוק · 1.95313 − 722.6
```

(`zoom.from_hero` בקובץ; מדויק עד עשירית נקודה על 1,704 נקודות.) מעל y=50 של המבט הקרוב ההר הרחוק "מתיישר" ולכן לא חופף: שם רק מעבר רך.

## מבנה `peak-poc.json`

```
geo, lights, slope [[סף במעלות, צבע] × 4], pal {day, night}
views.hero / views.zoom:
  W, H, px, images {אור: קובץ}
  proj {S, c, near, y_c, zref, step, F[], C[]}
  zf_runs, zf_lifts            מקדמי עובי למבט (רחוק 1, קרוב 1.514 ו-1.598)
  shadow {אור: [dx, dy]}       ההיסט על המסך של הצל של נקודה בגובה 100 מ׳ (רק לאורות היום)
  details {day: [...], night: [...]}, bshadow {אור: [[נקודות], ...]}
  pistes [{key, name, color, named, kind, lit, l: [[x,y,x,y,...], ...]}]
  lifts  [{name, gondola, wire, ground, towers [[xg,yg,x,y]], cabins [[x,y,xg,yg]], stations [[xg,yg]]}]
  sel {key: {segs: [{n, len, p: [x, y, נראה, מטרים מההתחלה, דרגת שיפוע] × n}], main, seen}}
  labels (רק ברחוק), from_hero (רק בקרוב)
runs {key: {name, color, ref, len, drop, top, bot, steep, near}}
check [...]
```

- `pistes[].l`: רק החלקים הנראים (מה שמאחורי רכס כבר נחתך).
- `sel`: רק מסלולים עם שם (28). `segs` הם חלקי המסלול מלמעלה למטה, בצעדים של 10 מ׳. חלקים שחולקים צומת חוברו; **חור במפה לא מגושר**, ולכן יש מסלולים בכמה חלקים (8 מתוך 28). `main` הוא החלק הארוך. "נראה" 0 פירושו שהנקודה מאחורי רכס: לא מציירים אותה. דרגת השיפוע 0 עד 3 היא אינדקס ב-`slope` (הכלל של האתר, אותם ספים: 15°, 25°, 30°).
- `runs[].near`: האם למסלול יש מבט קרוב (לפחות 85 אחוז ממנו בתמונה הקרובה). **רק ל-12 מתוך 28**: יש תמונה קרובה אחת, של הצד של Tatra.
- `runs[].name` הוא השם לתצוגה. `key` הוא מזהה בלבד (יש מפתח `u1234557981` ששמו New Goodaura 2).

### `details`

רשימת ציור מוכנה, לפי הסדר. כל פריט: `k` הוא הסוג.
- `l`: קו. `p` נקודות, `s` צבע, `w` עובי, `o` אטימות (אם אין: 1).
- `p`: מצולע. `p` נקודות, `f` מילוי, ואם יש `s` ו-`w`: קו מתאר.
- `c`: עיגול. `x`, `y`, `r`, `f`, `o`.
- `sh` (רק ביום): צל של בניין. המצולע הוא `bshadow[אור][i]`, המילוי `f`, האטימות `o`.
