### 2. מפת תבליט, הסלע של ההר, וצל מוטל

- **`ringrelief.webp`:** 800 על 800, 60 מ׳ לפיקסל, מעל הטבעת הפנימית (‎−24 עד ‎+24 ק״מ בשני הצירים, שורה 0 בצפון), מאריחי זום 11 (כ-56 מ׳ כאן). 156 קילובייט.
  - `R = 0.5 + שיפוע מזרחה / 3.2`, `G = 0.5 + שיפוע דרומה / 3.2`: אותו פענוח של `relief.webp`.
  - `B = (occ − 0.7) / 0.6`, כש-`occ = 1 + clamp(c1/60, −1, 1)·0.09 + clamp(c2/300, −1, 1)·0.11`, ו-`c1`, `c2` הם הגובה פחות ממוצע של 400 מ׳ ושל 3,000 מ׳.
  - `uv = (xz − (−24000)) / 48000`, בלי `flipY`, עם מיפמאפים.
- **השיידר:** `ring-ref.frag` בתיקייה הזו הוא הייחוס, מתוך `live_ref.html`. מה שחדש בו מול `RING_FS` של היום:
  - **הנורמל** מהמפה, שנכנסת בהדרגה: ב-500 המטרים הראשונים מחוץ להר וב-4 האחוזים האחרונים של הקופסה.
  - **הסלע** עם הגרעין של ההר, וגם מהאריח בקנה מידה גדול (420, 900, 2,400 ו-5,200 מ׳). בלי זה, מ-25 ק״מ הגרעין מתמזג לכתם אפור (המיפמאפים מוחקים אותו).
  - **`occ`** מכפיל את הצבע, כמו `rl.b` בהר.
- **צל:** לכל נקודה בשתי הטבעות, מחושב יחד עם הצל של ההר (`Sun.shadows`, אותו מפתח של 10 דקות, מחוץ לשרשור הציור) ומוחלק 1 2 1. מגיע לשיידר כמו `aShadow`. הגובה לצל: ההר בתוכו, הפנימית עד 24 ק״מ, והחיצונית אחר כך. צעדים של חצי תא, שגדלים עם המרחק, עד 24 ק״מ או עד שהקרן עוברת 5,200 מ׳. כ-55 אלף נקודות.

### 3. אוויר של גובה (אחד להר ולטבעת)

פונקציה אחת, `airOf(d, y)`, במקום השורה `far = uHaze.z*(1 − exp(−max(d − uHaze.x, 0)/uHaze.y))`, **גם ב-`FS` של ההר וגם בטבעת**:

```glsl
uniform vec4 uAir2;   // x = מרחק המצלמה × 1.5, y = 25000, z = 2800, w = 0.35
float airOf(float d, float y){
  float dens = mix(1.0, uAir2.w, smoothstep(uAir2.z, uAir2.z + 1800.0, y));
  float od = (clamp(d, uHaze.x, uAir2.x) - uHaze.x) / uHaze.y + max(d - uAir2.x, 0.0) / uAir2.y;
  return uHaze.z * (1.0 - exp(-od * dens));
}
```

- עד פעם וחצי ממרחק המצלמה, האובך זהה לשל היום. אחר כך הוא מתמלא לאט (25 ק״מ), והאוויר דליל יותר מעל 2,800 מ׳ (35 אחוז מהצפיפות מ-4,600 מ׳).
- כך הפסגות הגבוהות נשארות חדות, והעמקים שביניהן נמסים. **זה מה שיוצר את השכבות.**
- **השפעה על ההר:** החלק הרחוק שלו קצת פחות מעורפל. במבט הפתיחה כמעט לא רואים הבדל (לוח `Y02`, מבט הפתיחה).
