### 3. אוויר של גובה (אחד להר ולטבעת)

פונקציה אחת, `airOf(d, y)`, במקום השורה `far = uHaze.z*(1 − exp(−max(d − uHaze.x, 0)/uHaze.y))`, **גם ב-`FS` של ההר וגם בטבעת**:

```glsl
uniform vec4 uAir2;   // x = מרחק המצלמה × 1.5, y = 25000, z = 2800, w = 0.35
float airOf(float d, float y){
  float dens = mix(1.0, uAir2.w, smoothstep(uAir2.z, uAir2.z + 1800.0, y));
  float od = (clamp(d, uHaze.x, uAir2.x) - uHaze.x) / uHaze.y + max(d - uAir2.x, 0.0) / uAir2.y;
  return uHaze.z * (1.0 - exp(-od * dens));
}
```

- עד פעם וחצי ממרחק המצלמה, האובך זהה לשל היום. אחר כך הוא מתמלא לאט (25 ק״מ), והאוויר דליל יותר מעל 2,800 מ׳ (35 אחוז מהצפיפות מ-4,600 מ׳).
- כך הפסגות הגבוהות נשארות חדות, והעמקים שביניהן נמסים. **זה מה שיוצר את השכבות.**
- **השפעה על ההר:** החלק הרחוק שלו קצת פחות מעורפל. במבט הפתיחה כמעט לא רואים הבדל (לוח `Y02`, מבט הפתיחה).

**גאומטריה (בבנייה, פעם אחת):**
- **הטבעת הפנימית** שומרת את הגבהים שלה עד הקצה ומתחתיו. נקודה שלה מתחת להר יורדת 3 מ׳ בלבד (במקום `UNDER` והתפר של 900 מ׳). כך היא לא מבצבצת, ואין רצועה.
- **ההר:** נקודה שבמרחק `din` פנימה מהקצה, פחות מ-1,500 מ׳, מקבלת `y = h + (h_טבעת − h) · w`, כש-`t = 1 − din/1500` ו-`w = t²(3 − 2t)`. בקצה עצמו שני הגבהים זהים.
- אין משולשים נוספים.

**הפס, `ringband.webp` ו-`band.json`** (בתיקייה של הטבעת, ליד `ringrelief.webp`):

WebP בצבע עם שקיפות מוחק את הצבע איפה שהשקיפות 0, ובעמקים שטוחים זה יצר ריבועים. **228 ק״ב.** האפליקציה מחזירה אותן לטקסטורת RGBA אחת, בלי `flipY`, עם מיפמאפים (כ-2.2 מ״ב בזיכרון).

**שיידרים:**
