# סבב 34: קרב כדורי שלג, לראות את החבר׳ה (1.11.2026)

**בקנבס, עמוד "סבב 34" (גרסה 98). ממתין לפיני.** לבקשת סשן המנהל וסשן האייפון: פיני לא רואה את הדמויות בקרב כדורי שלג, כי היריבים רחוקים (החומה הרחוקה במרחק 10) והאופק ב-42 אחוז מגובה המסך.

הלוחות מצוירים מהמשחק של האתר (`shots.mjs`, מחליף רק את מספרי המסגור בזמן הצילום). באנדרואיד ובאייפון אותם מספרים בדיוק, ולכן אותן תמונות. שום דבר לא שונה בקוד. במשחק אין מצב לילה.

| היום | `ZF=10`, `Y0=42%` | |
| א (סשן האייפון) | החומה הרחוקה ב-7 במקום 10 (פי 1.4) | משנה מרחק וזמן מעוף: קושי |
