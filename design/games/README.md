# המשחקים

כל משחק עומד בפני עצמו, בקובץ אחד, עם שיאים והישגים משלו (נשמרים רק במכשיר). הרעיונות והתכנון: `research/game-feasibility.md` (סבבים 3 ו-4). משחק הגלישה "הירידה של החבר׳ה" נמצא ב-`design/round4/game/`.

בכל תיקייה: `game.src.html` הוא המקור, ו-`build.py` מאחד אותו עם הנתונים ל-`index.html`.

## הנהג של גודאורי

- **חמישה קטעים אמיתיים** של הכביש, מהעמק (1,661 מ׳) דרך גודאורי (2,194 מ׳) אל המעבר (2,392 מ׳) ובירידה ממנו. כל קטע נפתח אחרי שמסיימים את הקודם.
- **שליטה:** שמאלה וימינה, ושניהם יחד בלם. המיניבוס מאיץ לבד.
- **פיזיקה של סיבוב:** הכביש דורש כוח צידי לפי המהירות והעקמומיות האמיתית שלו. מה שהאחיזה לא מחזיקה דוחף החוצה, אל הגדר. על קרח האחיזה נמוכה.
- **נקודות:** עקיפת משאיות, "על הסנטימטר" מול רכב שבא ממול, החלקות בסיבובים, ופרות. רצף מכפיל.
- **סבלנות החבר׳ה:** שלוש מכות ונגמר. קילומטר בלי מכה מחזיר לב.
- **שלושה כוכבים לקטע:** להגיע, בלי מכה, ומשימה של הקטע.
- `road.py` מחלץ את הקו מנתוני האתר ומוסיף גבהים (`road.json`).
- נבדק בבוט שנוהג ובולם לפני סיבובים: סיים שלושה מתוך חמשת הקטעים. כל קטע לוקח לבוט 3 עד 5 דקות.
