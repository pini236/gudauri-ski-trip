# סבב 4: משחק הגלישה

עמוד "סבב 4: משחק הגלישה" בקנבס (https://claude.ai/artifact/TVdeDbFBhvFDZdhCKjcys4). שבעה מסכים לרעיונות מסבב הרעיונות 2 ב-`research/game-feasibility.md`.

| קובץ | מה רואים | אינטראקטיבי |
|---|---|---|
| `G1-PickFriend` | בוחרים אחד משישה החבר׳ה, כל אחד בצבע מעיל משלו. התכונה והמשפט מסומנים כמקום שפיני ימלא | כן |
| `G2-Descent` | "הירידה": מבט מאחורי הגולש על הקו האמיתי של Tatra 2, רוח הרפאים של דובי לפנים, זמן, מהירות, פרופיל צבוע לפי שיפוע, והשיפוע האמיתי בנקודה | אנימציה |
| `G3-GhostChallenge` | ההודעה בקבוצה ("פיני ירד ב-1:42.6, מי עוקף?") ומסך הפתיחה של המירוץ מול רוח הרפאים | אנימציה |
| `G4-PhotoFinish` | צילום סיום, טבלת תוצאות, "נקמה" ושליחת הכרטיס לקבוצה | אנימציה |
| `G5-HotelTournament` | ערב טורניר במלון: טלפון אחד, "מעבירים את הטלפון לשרוליק", טבלה חיה | אנימציה |
| `G6-LastLift` | "הרכבל האחרון": שקיעה, שעון שנגמר וכמה מהירות צריך | אנימציה |
| `G7-Caravan` | "השיירה": כל החבר׳ה יחד, "חכו לי!", אל נקודת המפגש | לא |

**מה אמיתי:** הקו של Tatra 2 (מ-OpenStreetMap), הגבהים והשיפוע ממודל הגובה, והנוף ברקע (הרינדור מדף הבית). **לדוגמה:** כל הזמנים, התוצאות וההודעות, התכונות והמשפטים של החברים, וצבעי המעילים (לבחירת פיני).

בנייה מחדש: `python3 design/round4/build.py` (דורש numpy).
