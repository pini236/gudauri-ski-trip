# סבב 13: תיקונים קטנים

ארבעה שינויים קטנים במראה, לבקשת סשן התיקונים (ענף `claude/fixes-night`), כל אחד לפני ואחרי, מצולמים בתוך האתר האמיתי בטלפון בהיר. בקנבס: עמוד "סבב 13: תיקונים קטנים". **שום דבר מזה לא בקוד עד אישור של פיני** (החלטה 18).

| # | מה | לפני | אחרי |
|---|---|---|---|
| 1 | כפתורי השפה בדף הפרטיות (`.pv-lang button`) | גובה 40 | גובה 44, לפי הכלל |
| 2 | הציורים בכרטיסי השיעור בבית הספר לסקי (`site/games/school`, המקור ב-`design/games/school`) | מילים בתוך הציור, נחתכות בשוליים בעברית ובאנגלית | בלי מילים בציור; מקרא קטן מתחתיו בצבעי הציור, שנשבר לשורות בכל שפה |
| 3 | "המשך עם גוגל" (באתר `W4`, באפליקציה `A2`) | עיגול עם G | הסמל הרשמי של גוגל. באתר כבר כך מ-2.10.2026, כי גוגל מציירת את הכפתור |
| 4 | "אני כבר בקבוצה" (באתר `W7` ודף הקבוצה, באפליקציה `Q5`, `Q10`) | המנהל רואה רק את שם החבר שמבקשים להיות | המבקש כותב "איך קוראים לך?", והמנהל רואה את שני השמות. השרת מקבל `display_name` ב-`request_reclaim` (בענף של סשן התיקונים) |

- `fixes.mjs`: מצלם את הלפני והאחרי (`ONLY=1234` לבחור סעיפים). השרת מדומה בסעיף 4, והשמות מומצאים.
- `build.py`: בונה את הלוחות לקנבס מהצילומים שהועלו.
