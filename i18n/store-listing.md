# דף החנות ברוסית ובגאורגית

**ממתין לבדיקת דובר.** תורגם ב-1.10.2026 מהטיוטות באנגלית ובעברית ב-`docs/PLAY.md` (סעיף "דף החנות"). **לא מעלים לקונסולה טקסט שלא נבדק.** המונחים לפי `i18n/glossary.md`. מה הדובר בודק קודם: `i18n/REVIEW.md`.

**כללים מ-`docs/PLAY.md` שחלים גם כאן:**
- בבדיקה הסגורה דף החנות נראה רק לבודקים. מתארים רק מה שבאמת בגרסה, ואת התיאור המלא מקצצים לפי מה שקיים.
- השם עד 30 תווים, התיאור הקצר עד 80, התיאור המלא עד 4,000. האורכים למטה נספרו בתווים.
- משפט "לא רשמית" והקרדיט ל-OpenStreetMap חובה בכל שפה.
- השם עדיין פתוח (החלטה 25). כאן הגיבוי, `Gudi`, עם תיאור בשפה המקומית בשביל החיפוש. כשיוחלט שם, מחליפים רק את המותג.
- **שמות המשחקים** לפי `i18n/glossary.md`. בגאורגית "გუნდაობა" היא המילה לקרב כדורי שלג.

כשמוסיפים שפה בקונסולה: `Grow users`, ואז `Store presence`, ואז `Main store listing`, ואז `Manage translations`. רוסית: `ru-RU`. גאורגית: `ka-GE`.

## רוסית (`ru-RU`)

**שם** (25 מתוך 30):
```
Gudi: карта трасс Гудаури
```

**תיאור קצר** (76 מתוך 80):
```
3D-карта Гудаури: трассы, крутизна, подъёмники, место встречи и снежные игры
```

**תיאור מלא:**
```
Карта горнолыжного курорта Гудаури (Грузия), построенная на реальных данных.

• Гора в 3D по настоящей модели рельефа, со всеми трассами и подъёмниками.
• Выберите трассу, и она окрасится по крутизне: профиль высот, «что впереди» и пролёт по трассе.
• Место встречи: выберите станцию подъёмника, день и время и отправьте своей компании.
• Состояние подъёмников, когда есть свежие данные. Когда их нет, приложение так и пишет.
• Ваша поездка: посадочный талон с обратным отсчётом.
• Снежные игры: «Спуск компании», «Горнолыжная школа», «Свежий снег», «Слияние снежков» и «Снежная битва».
• День и ночь по времени в Гудаури.
• Работает без связи, кроме видео и состояния подъёмников.

Точность прежде всего: каждая линия на карте взята из реального источника (OpenStreetMap, модель рельефа), а для каждого дополненного участка указаны источник и степень достоверности.

Неофициальное приложение. Не связано с Mountain Trails Agency (MTA), курортом Гудаури или каким-либо официальным органом. Названия и цвета трасс соответствуют официальной карте и приводятся только для узнавания.

Картографические данные © участники OpenStreetMap (ODbL).
```

## מה עוד חסר לדף החנות בשפות האלה

- **צילומי מסך בשפה:** כשהאפליקציה תדבר רוסית וגאורגית, צילומים מהאמולטור בכל שפה (`app/android/qa/`). עד אז הצילומים בעברית או באנגלית משותפים לכל השפות.
- **התמונה הראשית:** בלי טקסט בשפה (השלט נושא `GUDAURI`), ולכן אחת לכל השפות.
- **השם של MTA:** בגאורגית השם הרשמי מהאתר שלהם, "მთის ტრასების სააგენტო" (`glossary.md`, טבלת המקומות). ברוסית אין שם רשמי, ולכן הוא נשאר באנגלית.
