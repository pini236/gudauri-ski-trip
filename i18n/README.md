# שפות: עברית, אנגלית, רוסית, גאורגית

התיקייה הזו מחזיקה את כל מה שצריך כדי שהאתר והאפליקציות ידברו בארבע שפות (החלטה 32 ב-`docs/STATUS.md`). נכתבה ב-1.10.2026, בסשן השפות והצמיחה (שלב 14).

**האתר והאפליקציה קוראים מכאן** (מ-2.10.2026). האתר דרך `tools/build-site-strings.py`, ואפליקציית האנדרואיד דרך `tools/build-app-strings.py`. כל שינוי בטקסט נעשה כאן, ואחר כך מריצים את שני הכלים.

## מה יש כאן

| קובץ | מה בו |
|---|---|
| `glossary.md` | מילון המונחים: מונחי סקי, צבעי המסלולים, שמות המסלולים והרכבלים (עם מקור לכל שם), מקומות, שמות המשחקים ומונחי הממשק. **כל תרגום חדש מתחיל מכאן.** |
| `strings.json` | כל המחרוזות של האתר (דף הבית, המפה, נקודת המפגש, המשחקים, אודות, וחמשת המשחקים), בארבע השפות, בקובץ נתונים אחד. |
| `store-listing.md` | דף החנות ברוסית ובגאורגית, מתוך הטיוטות באנגלית ובעברית ב-`docs/PLAY.md`. |
| `REVIEW.md` | מה דובר הרוסית ודובר הגאורגית צריכים לבדוק, ובאיזה סדר. |
| `check.py` | בדיקת תקינות לקובץ המחרוזות (מפתחות, שפות, משתנים, צורות רבים). |

## מצב התרגום

- **עברית:** המקור. הועתקה מהאתר כמו שהיא.
- **אנגלית:** טיוטה של Claude. כדאי שמישהו יקרא, אבל זו לא חובה לפני העונה.
- **רוסית וגאורגית: לא נבדקו על ידי דובר.** כל מחרוזת מסומנת כך בקובץ עצמו (`"check": ["ru", "ka"]`). **החלטה 39 (2.10.2026):** לא מחכים לבדיקת דובר, והסימון נשאר כמידע. באתר הן עדיין נפתחות רק בקישור (`?lang=ru`), עד אישור של פיני להפעיל אותן לפי שפת הדפדפן.

## הפורמט של `strings.json`

```json
{
  "meta": { "languages": ["he", "en", "ru", "ka"], "source": "he", ... },
  "strings": {
    "nav.map": {
      "he": "מפת מסלולים", "en": "Trail map", "ru": "Карта трасс", "ka": "ტრასების რუკა",
      "where": "site/index.html", "check": ["ru", "ka"]
    }
  }
}
```

- **מפתח:** `<אזור>.<שם>`, באותיות קטנות ובנקודות. האזורים: `meta` (כותרות ותיאורים לשיתוף), `nav`, `home`, `ticket`, `about`, `map`, `run`, `lift`, `status`, `meet`, `games`, ואחריהם משחק לכל אזור (`game.descent`, `game.school`, `game.fresh`, `game.merge`, `game.snowball`), ו-`common` למילים שחוזרות.
- **`where`:** הקובץ באתר שממנו המחרוזת נלקחה. עוזר למצוא אותה כשהאתר יחובר.
- **`note`** (לא חובה): הקשר למתרגם ולבודק. למשל "כפתור, קצר", "שם המשחק", "מופיע על שלט צר".
- **`check`:** השפות שעוד ממתינות לבדיקת דובר. כשדובר מאשר, מוחקים את השפה מהרשימה. כשהרשימה ריקה, מוחקים את השדה.
- **משתנים:** בסוגריים מסולסלים, `{n}`, `{name}`, `{time}`. אותם משתנים בכל ארבע השפות. הסדר יכול להשתנות לפי השפה.
- **צורות רבים:** כשהמחרוזת תלויה במספר, הערך הוא אובייקט לפי הקטגוריות של CLDR, במקום מחרוזת:
  - עברית: `one`, `two`, `other`
  - אנגלית וגאורגית: `one`, `other` (בגאורגית שם העצם אחרי מספר תמיד ביחיד)
  - רוסית: `one`, `few`, `many`, `other` (1 трасса, 2 трассы, 5 трасс)
- **מה לא נכנס:** שמות המסלולים והרכבלים כפי שהם בנתונים (הם באותיות לטיניות בכל השפות, ראו `glossary.md`), שמות החברים, קודי שדות תעופה ומספרי טיסה, וטקסט שמגיע מקבצי הנתונים (`site/data/`). הערות ומקורות בתוך נתוני המסלולים יתורגמו בנפרד, כשמחליטים איך (ראו "פתוח").

## איך משתמשים בזה בכל פלטפורמה (כשמגיעים לזה)

- **אתר (מומש, 2.10.2026):**
  - הפקודה `python3 tools/build-site-strings.py` כותבת את `site/i18n/<lang>.json` (האתר) ואת `site/i18n/game-<id>.<lang>.json` (כל משחק בנפרד).
  - `site/js/i18n.js` נטען ראשון ב-`<head>`: בוחר שפה, קובע `lang` ו-`dir`, טוען את הגופנים של השפה, ומתרגם את הדף. בקוד: `T('key', {vars})`; במשחקים `L('key', 'עברית', {vars})`, שהעברית בו היא גם הגיבוי.
  - בדף: `data-i18n` (טקסט), `data-i18n-attr="aria-label:key"` (תכונות), `data-i18n-html` (טקסט עם תגיות שלנו).
  - **איך נבחרת השפה:** `?lang=en` (נשמר בדפדפן; `?lang=auto` מבטל), אחר כך הבחירה השמורה, ואחר כך הדפדפן: עברית לכל מי שיש לו עברית בשפות הדפדפן או אזור הזמן של ישראל, אחרת השפה הראשונה ברשימה `RELEASED` שהדפדפן מבקש, ואחרת אנגלית. **עדיין אין בורר שפה גלוי:** הוא לא עוצב בקנבס.
  - בדיקות: `python3 tools/check-site-i18n.py` (כל מפתח קיים, אין עברית בקוד, כל טקסט בדף מכוסה), ו-`tests/i18n.spec.ts`.
- **אנדרואיד:** `values/strings.xml`, `values-en/`, `values-ru/`, `values-ka/` (עם `plurals`), שנוצרים מכאן בבנייה, כמו הנתונים (`tools/build-app-data.py`).
- **אייפון:** קטלוג מחרוזות (`Localizable.xcstrings`) שנוצר מכאן.
- המפתחות זהים בכל הפלטפורמות, ולכן גם אירועי המדידה (`docs/GROWTH.md`) יכולים לציין שפה בלי תלות בפלטפורמה.

## כללים

1. **שמות המסלולים והרכבלים לא מתורגמים.** הם נשארים כמו בשלטים בהר ובמפה הרשמית, באותיות לטיניות, בכל השפות. בגאורגית וברוסית מותר להוסיף את האיות המקומי בסוגריים במקומות של הסבר (לא על המפה), לפי `glossary.md`.
2. **צבעי המסלולים** לפי המפה הרשמית (כלל דיוק 3), ובמילים של `glossary.md`.
3. **השלטים מתהפכים בשפות משמאל לימין:** החץ מצביע קדימה בכיוון הקריאה (החלטה 32). זה עניין של עיצוב, לא של הטקסט.
4. **גופנים:** Karantina ו-IBM Plex Sans Hebrew לא מכסים קירילית וגאורגית. בחירת גופנים נעשית בקנבס (`docs/APP-NATIVE.md`, החלטה 13).
5. **פנייה למשתמש:** ברוסית ב-"вы" (באות קטנה), בגאורגית בגוף שני רבים (თქვენ). באנגלית בגובה העיניים, כמו בעברית.
6. **טקסט חדש באתר או באפליקציה** נכנס קודם לכאן, בעברית ובאנגלית, ומסומן `check` לרוסית ולגאורגית.

## בדיקה

```
python3 i18n/check.py
```

בודקת שבכל מחרוזת יש ארבע שפות, שהמשתנים זהים, שצורות הרבים נכונות לכל שפה, ומדפיסה כמה מחרוזות עוד ממתינות לבדיקת דובר.
