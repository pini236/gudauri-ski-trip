אתר היערכות לחופשת הסקי בגודאורי, גאורגיה (טיסה ב-10.1.2027), בשבילי ובשביל החברים.

- **האתר החי ב-claude.ai:** https://claude.ai/artifact/1uDUdt45A2c77zooPZBGYK
- **קנבס העיצוב:** https://claude.ai/artifact/TVdeDbFBhvFDZdhCKjcys4

## מה האתר עושה

- **דף בית:** קו הרכס כפי שנראה מהכפר גודאורי, מחושב מנתוני הגובה. כרטיס הטיסה של הקבוצה עם ספירת ימים, ורשימת החברים. שלט הכוונה לחלקי האתר.
- **מפת מסלולים:** מודל תלת-ממדי של ההר האמיתי ומבט על עם תבליט וקווי גובה. כל המסלולים והרכבלים לפי המפה הרשמית של MTA. לחיצה על מסלול פותחת פרטים: אורך, גבהים, שיפועים, חיבורים, מקור, רמת ודאות וסרטונים.
- **מצב כהה** בפלטת "לילה בהר".

## להריץ מקומית

הנתונים נטענים ב-`fetch`, ולכן צריך שרת מקומי. אין שלב בנייה.

```
npm install
npm start
```

ואז לפתוח את הכתובת `http://127.0.0.1:4173`. הבדיקות: `npm test`.

- המודל התלת-ממדי טוען את three.js r128 מ-cdnjs. בלי רשת האתר עובר אוטומטית למבט על.
- הגופנים (Karantina, IBM Plex Sans Hebrew) נטענים מ-Google Fonts.

## פריסה ב-Vercel

אתר סטטי, בלי בנייה:

- **Framework Preset:** Other
- **Root Directory:** `site`
- **Build Command:** ריק

**נתונים:** פרטי הטיסה והחברים ב-`site/data/trip.json`, והסרטונים ב-`site/data/videos-seed.json`. האתר מציג אותם לקריאה בלבד, ולעדכון עורכים את הקובץ ועושים commit. הפריסה ב-Vercel אוטומטית בכל מיזוג ל-`main`. התחברות ומסד נתונים הם רעיון לעתיד (`docs/ROADMAP.md`).
