## מה האתר עושה

- **דף בית:** הנוף האמיתי מעל New Gudauri, מרונדר ממודל הגובה (`design/round3/panorama.py`), שמשתנה לפי השעה בגודאורי: בוקר, צהריים, שעת זהב, שקיעה ורודה ולילה עם כוכבים ואורות בכפר. כרטיס הטיסה כמו כרטיס עלייה למטוס: כרטיס הלוך וכרטיס חזור שלמים, אחד מאחורי השני, שמתחלפים בנגיעה, וספח עם ספירת ימים שנתלש בנגיעה, עם צלילים ורטט. בלילה הכרטיס כהה עם הדפס זוהר. ורשימת החברים. שלט הכוונה לחלקי האתר.
- **מפת מסלולים:** מודל תלת-ממדי של ההר האמיתי ומבט על עם תבליט וקווי גובה. כל המסלולים והרכבלים לפי המפה הרשמית של MTA. לחיצה על מסלול צובעת אותו ואת פני השטח סביבו לפי השיפוע מלמעלה למטה ופותחת פרטים: אורך, גבהים, פרופיל גובה עם גרירה, "מה מחכה לך", השוואה, חיבורים, מקור, רמת ודאות, סרטונים וטיסה במורד המסלול בתלת-ממד, עם נקודה ופס מיקום על המפה. לכל מסלול יש קישור ישיר לשיתוף (`#map/run/<שם>`).
- **מצב רכבלים:** מה פתוח עכשיו, מתוך `/api/status` (פונקציה שתיכתב כשהדף של MTA יעבוד בדצמבר). עד אז, ובכל פעם שאין נתון עדכני, שלטים מושלגים ו"אין מידע". לא מנחשים.
- **נקודת מפגש:** מתחילים בלי בחירה, ובוחרים תחנת רכבל, יום ושעה (ומבטלים בכפתור, בשטח ריק או בסיכה), ומקבלים כרטיס מפגש, דרכים להגיע אליה, ושיתוף לקבוצה בוואטסאפ, בתמונה או בקישור (`#meet/...`). בלי מסד נתונים.
- **משחקים** (`#games`): חמשת המשחקים, כל אחד בעמוד משלו (`site/games/<שם>/`): הירידה של החבר׳ה, בית הספר לסקי, שלג טרי, איחוד כדורי שלג וקרב כדורי שלג. השיאים נשמרים רק בדפדפן.
- **מדיניות פרטיות** (`/privacy`, באנגלית `/privacy#en`): נבנית מ-`docs/PRIVACY.md`, עם קישור מדף הבית ומעמוד האודות.
- **אודות והגדרות** (`#about`): צליל, רטט, מצב תצוגה ואיפוס שיאים (חלים גם על המשחקים, דרך `site/js/prefs.js`), מי בנה את האתר, וכל הקרדיטים והרישיונות.
- **יום ולילה:** כפתור עם שלושה מצבים, אוטומטי (לפי השעה והשקיעה בגודאורי), יום ולילה, ושעון גודאורי לידו. הבחירה נשמרת בדפדפן. גם ההר בתלת-ממד מואר לפי השעה: שמש וצל אמיתיים, שקיעה ואור ירח.

## להריץ מקומית

הנתונים נטענים ב-`fetch`, ולכן צריך שרת מקומי. אין שלב בנייה.

```
npm install
npm start
```

ואז לפתוח את הכתובת `http://127.0.0.1:4173`.

**בדיקות:** הבדיקה המלאה (ארבעת המצבים) רצה ב-GitHub בכל דחיפה. מקומית רק מה שהשתנה, במצב אחד: `npm run test:quick -- tests/<קובץ>.spec.ts` (אפשר להוסיף `-g "<שם>"`); `npm test` מריץ הכל בארבעת המצבים, וזה איטי בסביבת הענן. בדיקות השפות: `python3 i18n/check.py` ו-`python3 tools/check-site-i18n.py` (רצות גם ב-GitHub).

**משחקים:** המקור של כל משחק ב-`design/games/` (ומשחק הגלישה ב-`design/round4/game/`). אחרי כל שינוי במשחק, מעתיקים אותו לאתר:

```
python3 tools/build-games.py
```

- המודל התלת-ממדי טוען את three.js r128 מ-cdnjs. בלי רשת האתר עובר אוטומטית למבט על.
- הגופנים נטענים מ-Google Fonts: Karantina ו-IBM Plex Sans Hebrew בעברית, ובשפות האחרות Oswald (כותרות ברוסית), Noto Sans Georgian ו-IBM Plex Sans (החלטה 36).

## פריסה ב-Vercel

אתר סטטי, בלי בנייה:

- **Framework Preset:** Other
- **Root Directory:** `site`
- **Build Command:** ריק

**נתונים:** "הטיול שלך" נשמר בדפדפן בלבד (`gud-trip`), ודף הבית מציג את הכרטיס של מי שמסתכל או כרטיס ריק. הטיסה והשמות של החבר׳ה ירדו מהאתר (החלטה 27, סבב 12); עותק לקנבס ב-`design/data/trip.json`. הסרטונים ב-`site/data/videos-seed.json`. האתר מציג אותם לקריאה בלבד, ולעדכון עורכים את הקובץ ועושים commit. הפריסה ב-Vercel אוטומטית בכל מיזוג ל-`main`. התחברות ומסד נתונים הם רעיון לעתיד (`docs/ROADMAP.md`).
