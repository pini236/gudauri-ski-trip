# האתר

אתר סטטי בלי שלב בנייה. `index.html` הוא תבנית בלבד, והקוד והנתונים בקבצים נפרדים.

## מבנה

| קובץ | מה הוא |
|---|---|
| `index.html` | המבנה של הדפים (בית, מפה, נקודת מפגש, משחקים, ואודות והגדרות) ושכבת טעינה |
| `vercel.json` | כותרות אבטחה (כולל מדיניות אבטחת התוכן, R-3), `noindex` ומטמון לנתונים. Vercel קורא אותו מתיקיית ה-Root, שהיא `site`; השרת המקומי (`tools/serve.mjs`) שולח את אותן כותרות |
| `privacy.html` | מדיניות הפרטיות (`/privacy`, באנגלית `/privacy#en`). **לא עורכים כאן:** נבנה מ-`docs/PRIVACY.md` בפקודה `python3 tools/build-privacy.py` |
| `og.jpg`, `favicon.svg` | תמונת שיתוף (מקור ב-`../design/og/`) ואייקון |
| `css/site.css` | כל העיצוב. הצבעים מוגדרים כמשתנים ב-`:root` |
| `js/relief.js` | הספרייה `GudRelief`: טעינת מודל הגובה, חישובי גובה ושיפוע, תבליט דו-ממדי ותצוגה תלת-ממדית (three.js) |
| `js/i18n.js`, `js/lang-picker.js` | ארבע השפות: `i18n.js` בוחר שפה (קישור, בחירה שמורה, דפדפן), קובע כיוון וגופנים ומתרגם דף ומשחקים מ-`i18n/*.json`; `lang-picker.js` הוא הבורר בעמוד ההגדרות. הקבצים ב-`i18n/` נוצרים מ-`../i18n/strings.json` בפקודה `python3 tools/build-site-strings.py` (לא עורכים אותם) |
| `js/telemetry.js` | מדידת שימוש (PostHog) ושגיאות (Sentry), בלי פרטים מזהים ועם מתג כיבוי בהגדרות (החלטות 32 ו-37) |
| `js/prefs.js` | ההגדרות של צליל ורטט (`gud-prefs` בזיכרון הדפדפן). נטען ראשון באתר ובכל משחק, ומשתיק צליל או רטט אם כובו |

| `js/account.js` | חשבונות וקבוצות (סבב 12): כניסה, חשבון, מחיקת חשבון, הזמנה וקבוצה, מול השרת (`server/CONTRACT.md`). אורח לא פונה לשרת |

| `js/vendor/three-r128.min.js`, `posthog-1.436.1.no-external.js`, `sentry-8.38.0.min.js` | three.js (MIT), PostHog (MIT, הגרסה בלי תוספים חיצוניים) ו-Sentry (MIT), בגרסה נעוצה, מהאתר עצמו ולא משרת אחר (R-3). שדרוג: להחליף את הקובץ ואת השם בקוד |
| `js/privacy.js`, `games/<שם>/game.js` | הסקריפטים של דף הפרטיות ושל כל משחק, בקובץ נפרד, כי המדיניות לא מריצה סקריפט שכתוב בתוך הדף. נבנים בכלים, לא עורכים כאן |

## הרצה מקומית

הנתונים נטענים ב-`fetch`, ולכן צריך שרת. מהשורש של הריפו:

```
npm install
npm start
```

ואז לפתוח את הכתובת `http://127.0.0.1:4173`.

## בדיקות

```
npm run test:quick -- tests/<קובץ>.spec.ts    # מקומית: מה שהשתנה, במצב אחד (אפשר להוסיף -g "<שם>")
npm test                                         # הכל, בארבעת המצבים (איטי בסביבת הענן)
python3 tools/check-site-i18n.py                 # שכל הטקסט מקובץ השפות, והעברית ב-HTML זהה לו
```

בדיקות Playwright בארבעה מצבים: מחשב וטלפון, בהיר וכהה. **הבדיקה המלאה רצה ב-GitHub בכל דחיפה** (`.github/workflows/tests.yml`), ושם ממתינים לה לפני מיזוג. הצילומים נשמרים ב-`test-results/`.

הבדיקות רצות מול `tools/serve.mjs`, ששולח את אותן כותרות כמו Vercel (כולל מדיניות אבטחת התוכן) ודוחס כמו Vercel. כל בדיקה נכשלת על הפרה של המדיניות (`tests/csp-listen.ts`), ו-`tests/csp.spec.ts` עובר על כל הדפים והמשחקים. **מקום חדש שהאתר פונה אליו** (שרת, סקריפט, תמונה, מסגרת) **חייב שורה במדיניות ב-`vercel.json`**, וסקירה של הארכיטקט אם זה שירות חדש.

## הורדת האפליקציה

בדף הבית מופיע שלט "אפליקציה לאנדרואיד", **רק אם** הקובץ `downloads/gudauri-2027.apk` קיים. לפרסום מעלים את הקובץ לתיקייה `site/downloads/` ודוחפים. אין צורך בשינוי קוד. (האפליקציה של ChatGPT ב-`chatgpt/android-native/`. האפליקציה החדשה תופץ דרך גוגל פליי, ואז השלט יפנה לחנות.)

## ניווט

שני דפים באותו קובץ: `#home` (ברירת מחדל) ו-`#map`. המפה, והמודל התלת-ממדי בפרט, נבנים רק בפעם הראשונה שנכנסים לדף המפה.

## טיסה וסרטונים

קבצי נתונים בריפו, בלי מסד נתונים ובלי התחברות. האתר מציג אותם לקריאה בלבד.

- **"הטיול שלך"** (`#trip`): טופס שנשמר רק בדפדפן (`localStorage`, המפתח `gud-trip`), והכרטיס בדף הבית נבנה ממנו (`MYTRIP` ו-`TRIPFORM` ב-`js/app.js`). בלי טיול: כרטיס ריק ושלט מצב העונה.
- **חשבונות וקבוצות** (`#signin`, `#account`, `#account/delete`, `#join/<קוד>`, `#group`): `js/account.js`. הכתובות `/j/<אסימון>`, `/join/<קוד>` ו-`/account` מפנות לשם (`vercel.json`). מזהה הלקוח של גוגל לאתר נכנס ל-`GOOGLE_CLIENT_ID` בראש הקובץ.
- הטיסה והשמות של החבר׳ה כבר לא באתר (פיני, 2.10.2026). עותק לבוני הקנבס הישנים ב-`design/data/trip.json`, שלא נפרס.
- `data/videos-seed.json`: סרטונים לפי מסלול, מוצגים כנגן מוטמע (תמונה ממוזערת שנטענת מיוטיוב). נוצר אוטומטית מ-`../tools/videos-curated.json` (ראו `research/videos.md`).

לסרטונים עורכים את `tools/videos-curated.json` ומריצים `python3 tools/build-videos.py`.

## ערכות צבע

כל הצבעים מוגדרים כמשתנים ב-`:root`. מצב כהה מוגדר גם דרך `prefers-color-scheme` וגם דרך `data-theme="dark"`. פני השטח בתלת-ממד תמיד מושלגים, ולכן התוויות בתלת-ממד שומרות על הצבעים הבהירים גם במצב כהה.
