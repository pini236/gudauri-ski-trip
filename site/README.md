# האתר

אתר סטטי בלי שלב בנייה. `index.html` הוא תבנית בלבד, והקוד והנתונים בקבצים נפרדים.

## מבנה

| קובץ | מה הוא |
|---|---|
| `index.html` | המבנה של הדפים (בית, מפה, נקודת מפגש, משחקים, ואודות והגדרות) ושכבת טעינה |
| `vercel.json` | כותרות אבטחה, `noindex` ומטמון לנתונים (Vercel קורא אותו מתיקיית ה-Root, שהיא `site`) |
| `og.jpg`, `favicon.svg` | תמונת שיתוף (מקור ב-`../design/og/`) ואייקון |
| `css/site.css` | כל העיצוב. הצבעים מוגדרים כמשתנים ב-`:root` |
| `js/relief.js` | הספרייה `GudRelief`: טעינת מודל הגובה, חישובי גובה ושיפוע, תבליט דו-ממדי ותצוגה תלת-ממדית (three.js) |
| `js/prefs.js` | ההגדרות של צליל ורטט (`gud-prefs` בזיכרון הדפדפן). נטען ראשון באתר ובכל משחק, ומשתיק צליל או רטט אם כובו |
| `js/app.js` | הסקריפט הראשי: טעינת הנתונים, הניווט בין הדפים, המפה הדו-ממדית, פאנל הפרטים, סינון, כרטיס הטיסה וסרטונים |
| `data/terrain.json` | מודל הגובה (DEM), תמונת התבליט, קווי גובה, סביבה (כפר, כבישים, מים) ופסגות |
| `data/trip.json`, `data/videos-seed.json` | הטיסה של הקבוצה, החברים והסרטונים |
| `games/<שם>/index.html` | חמשת המשחקים, כל אחד קובץ אחד. **לא עורכים כאן:** הם נבנים מ-`design/` בפקודה `python3 tools/build-games.py`, שמוסיפה גם קישור חזרה לעמוד המשחקים |
| `games/thumbs/` | תמונות הכרטיסים בעמוד המשחקים |
| `audio/ticket-*.wav` | צלילי כרטיס הטיסה: קריעה, החלקה והנחה. המקורות והרישיונות ב-`design/round7/audio/CREDITS.md`, והקרדיט מוצג בתחתית דף הבית |
| `data/runs-and-lifts.json` | המסלולים והרכבלים, בקואורדינטות `[lat, lon]`, כולל חיבורים ומחקר ההשלמה |

## הרצה מקומית

הנתונים נטענים ב-`fetch`, ולכן צריך שרת. מהשורש של הריפו:

```
npm install
npm start
```

ואז לפתוח את הכתובת `http://127.0.0.1:4173`.

## בדיקות

```
npm test
```

בדיקות Playwright בארבעה מצבים: מחשב וטלפון, בהיר וכהה. הצילומים נשמרים ב-`test-results/`.

## הורדת האפליקציה

בדף הבית מופיע שלט "אפליקציה לאנדרואיד", **רק אם** הקובץ `downloads/gudauri-2027.apk` קיים. לפרסום מעלים את הקובץ לתיקייה `site/downloads/` ודוחפים. אין צורך בשינוי קוד. (האפליקציה של ChatGPT ב-`chatgpt/android-native/`. האפליקציה החדשה תופץ דרך גוגל פליי, ואז השלט יפנה לחנות.)

## ניווט

שני דפים באותו קובץ: `#home` (ברירת מחדל) ו-`#map`. המפה, והמודל התלת-ממדי בפרט, נבנים רק בפעם הראשונה שנכנסים לדף המפה.

## טיסה וסרטונים

קבצי נתונים בריפו, בלי מסד נתונים ובלי התחברות. האתר מציג אותם לקריאה בלבד.

- `data/trip.json`: הטיסה של הקבוצה (כולל קודי שדות התעופה, `fromCode` ו-`toCode`), הכבודה (`baggage`), ימי הסקי (`skiDays`) ורשימת החברים.
- `data/videos-seed.json`: סרטונים לפי מסלול, מוצגים כנגן מוטמע (תמונה ממוזערת שנטענת מיוטיוב). נוצר אוטומטית מ-`../tools/videos-curated.json` (ראו `research/videos.md`).

לעדכון פרטי הטיסה עורכים את `trip.json` ועושים commit. לסרטונים עורכים את `tools/videos-curated.json` ומריצים `python3 tools/build-videos.py`.

## ערכות צבע

כל הצבעים מוגדרים כמשתנים ב-`:root`. מצב כהה מוגדר גם דרך `prefers-color-scheme` וגם דרך `data-theme="dark"`. פני השטח בתלת-ממד תמיד מושלגים, ולכן התוויות בתלת-ממד שומרות על הצבעים הבהירים גם במצב כהה.
