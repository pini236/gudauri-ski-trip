# האתר

קובץ אחד, `index.html`, בלי תלויות בנייה.

## מבנה הקובץ

| חלק | מה הוא |
|---|---|
| `<script id="terrain" type="application/json">` | מודל הגובה (DEM), תמונת התבליט, קווי גובה, סביבה (כפר, כבישים, מים) ופסגות. זהה ל-`data/terrain.json` |
| `<script id="data" type="application/json">` | המסלולים והרכבלים, בקואורדינטות `[lat, lon]`, כולל חיבורים ומחקר ההשלמה. זהה ל-`data/runs-and-lifts.json` |
| סקריפט `GudRelief` | טעינת המודל, חישובי גובה ושיפוע, והתצוגה התלת-ממדית (three.js) |
| הסקריפט הראשי | שני הדפים, המפה הדו-ממדית, פאנל הפרטים, סינון, כרטיס הטיסה וסרטונים |

## ניווט

שני דפים באותו קובץ: `#home` (ברירת מחדל) ו-`#map`. המפה, והמודל התלת-ממדי בפרט, נבנים רק בפעם הראשונה שנכנסים לדף המפה.

## נתונים משותפים (רק בתוך claude.ai)

- **סרטונים:** collection `videos`, מסמך לכל סרטון.
- **כרטיס הטיסה:** מסמך `trip/flight` עם `from`, `to`, `flight`.
- **מחקר המסלולים החסרים:** collection `missingRuns` (האתר לא קורא ממנו; הנתונים כבר מוטמעים ב-`data`).

כתיבה דורשת הרשאת Contributor לארטיפקט. מחוץ ל-claude.ai האתר עובד בקריאה בלבד.

## ערכות צבע

כל הצבעים מוגדרים כמשתנים ב-`:root`. מצב כהה מוגדר גם דרך `prefers-color-scheme` וגם דרך `data-theme="dark"`. פני השטח בתלת-ממד תמיד מושלגים, ולכן התוויות בתלת-ממד שומרות על הצבעים הבהירים גם במצב כהה.
