# ChatGPT Android test download

This branch holds the verified test APK and its public checksum/build manifest.
Source is pinned by `sourceCommit` in the manifest and kept in a separate branch.
These artifacts are not website downloads and are not a production/store update.

Install the `.apk` on Android 8 or newer, then open **גודאורי · בדיקת ChatGPT**.
It installs alongside the old app. Keep the old app installed; its preferences
remain there. Meetings and interactive route profiles are included; full parity
and real-phone acceptance are still pending.

See [`../play/TESTING_HE.md`](../play/TESTING_HE.md) for the short test checklist.
