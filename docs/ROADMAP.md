## משתמשים וקבוצות

**כיוון (30.9.2026):** האתר והאפליקציה ישמשו כל אחד, לא רק את החברים. הצעת פיני: הרשמה עצמית במייל או בטלפון, הזדהות בקוד שנשלח, ויצירת קבוצה שדרכה החברים רואים מה שרלוונטי להם. או אפשרות אחרת: רק חלק המפה ציבורי.

| נושא | הערות |
|---|---|
| **הזדהות** | קוד חד פעמי במייל (Supabase תומך, ובחינם ברמה הבסיסית). **לא לשלוח סיסמה קבועה במייל**, רק קוד חד פעמי או קישור התחברות. קוד ב-SMS דורש ספק SMS בתשלום לכל הודעה, ופתוח לניצול לרעה (שליחה המונית של הודעות), ולכן כדאי להתחיל במייל בלבד |
| **קבוצות** | טבלת קבוצות וטבלת חברים בקבוצה, עם הרשאות בגישה למידע: חבר רואה רק את הקבוצות שלו. יצירה והצטרפות בקישור הזמנה |
| **מה ציבורי ומה מוגבל** | ההמלצה: המפה, המסלולים והסרטונים ציבוריים לכולם. התאמה אישית, קבוצה, טיסה והעדפות רק אחרי התחברות |
| **פרטיות** | דף מדיניות פרטיות, הסכמה, ואפשרות למחוק חשבון. **לבדוק את הדרישות הרלוונטיות** (חוק הגנת הפרטיות בישראל, ובנוסף GDPR למשתמשים מאירופה) |
| **תלות** | שכבת `Store` ופרויקט Supabase חדש (ראו למטה בסעיף "האתר והטכנולוגיה") |
