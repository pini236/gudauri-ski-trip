# טיוטה: הנוסחים של רגעי יום הגלישה (החלטה 76)

**טיוטה. לא ב-`i18n/strings.json` עד שפיני בוחר טון** (סבב 29, שאלה 11). תוכן, ניסוח ושפות, 30.10.2026, לבקשת סשן המנהל.

מנוע הרגעים (`tools/dayrec/moments.py`, הסעיף "הרגעים" ב-`tools/dayrec/README.md`) מחזיר לכל רגע מפתח ופרמטרים בלבד. כאן הנוסח לכל מפתח, בשלושה טונים ובארבע השפות. הנוסחים עצמם בקובץ הנתונים שבתיקייה הזו:

```
docs/handoff/2026-10-30-dayrec-moments-copy/moments-copy.json
```

## שלושת הטונים

| טון | מה הוא | דוגמה (האדום הראשון) |
|---|---|---|
| `play`: שובב ולא לועג (ההמלצה) | כותרת ושורה, עם חיוך קטן. לא צוחק על הגולש, ולא משבח מהירות | "האדום הראשון שלך" · "Kudebi 1 ב-13:34. מעכשיו הוא שלך." |
| `dry`: יבש | כותרת ושורה של עובדות, כמו בלוח של שדה תעופה | "האדום הראשון" · "Kudebi 1, 13:34" |
| `data`: נתונים בלבד | רק כותרת קצרה מעל המספר, בלי שורה | "אדום ראשון" |

באנגלית הנוסחים נכתבו מחדש בכל טון, ולא תורגמו מהעברית. גם ברוסית ובגאורגית יש בחירה חופשית, אבל בלי בדיקת דובר (החלטה 39).

## איך הקובץ בנוי

- **`shared`:** שישה מפתחות לכל הטונים: שמות הגבהים להשוואה (`moment.ref.<id>`) ושני הכפתורים של שאלת הנפילה.
- **`tones`:** לכל טון, מפתח ובו ארבע השפות. **כל ערך הוא רשימה של גרסאות.** האפליקציה מציגה את הגרסה במקום `seed % מספר הגרסאות`, וכך שתי האפליקציות בוחרות אותה גרסה.
- **מפתחות המשנה:** כשהשפה צריכה ניסוח אחר לפי פרמטר, המפתח מתפצל:

| מפתח | התפצלות לפי |
|---|---|
| `moment.fastest`, `moment.fall` | `run` כשהרגל על מסלול, `off` בכל מקרה אחר |
| `moment.longest_descent` | `run` כשיש שם מסלול, `norun` כשהרשימה ריקה |
| `moment.first_color` | `red` או `black`, ואז `first` כש-`first_ever` אמת, אחרת `again` |
| `moment.record` | `what`: `max_kmh`, `longest_m`, `drop_m`, `descents`, `ski_dist_m` |
| `moment.all_color` | הצבע |

- **בטון `data`** יש רק כותרות, בלי מפתחות משנה (חוץ מהצבע בראשון ובכולם).
- **כותרת ושורה:** `<מפתח>.title` ו-`<מפתח>.line`, כמו בלוחות של מעצב המוצר.
- **שני מפתחות שלא מהמנוע:** `moment.story.head` (הכותרת של כרטיס היום, מהמספרים של היום) ו-`moment.last_descent.falls` (שורה בכרטיס על הרכבל, רק כשהייתה נפילה).

## הפרמטרים בנוסח

האפליקציה ממירה את הפרמטרים של המנוע ומעצבת אותם לפי השפה (פסיק עשרוני ברוסית, למשל):

| בנוסח | מאיפה |
|---|---|
| `{kmh}` | `kmh` (או `max_kmh` בכרטיס על הרכבל), מספר שלם |
| `{km}` | `dist_m` חלקי 1,000, ספרה אחת אחרי הנקודה |
| `{drop}` | `drop_m`, מספר שלם |
| `{min}` | `moving_s` או `s` חלקי 60, מעוגל |
| `{time}` | `t` בשעון גודאורי, שעות ודקות |
| `{run}` | השם של המסלול הראשון ב-`runs` (או `run`) |
| `{runs}` | כל השמות, מחוברים לפי השפה |
| `{n}` | כמה: מסלולים חדשים, מסלולים בצבע, נפילות או ירידות ביום |
| `{lift}` | `lift` |
| `{times}` | `times`; בלי `.0` כשהמספר שלם |
| `{ref}` | הנוסח של `moment.ref.<ref>` |
| `{value}`, `{before}` | בשיאים, ביחידה שבשורה (`longest_m` ו-`ski_dist_m` בקילומטרים) |
| `{day}` | מספר יום הסקי בטיול, כמו בכרטיס (S-35) |

**דקדוק:** ברוסית ובגאורגית `moment.ref` כבר בצורת הקניין, כי המשפט צריך אותה ("выше башни Азриэли", "ვიდრე აზრიელის კოშკის სიმაღლე"). צורות הרבים לפי `i18n/README.md`. ברוסית `{times}` הוא מספר עם נקודה, ולכן "в 3,4 раза" נופל לקטגוריה `other`.

## הכללים שנשמרו

- **`fall` תמיד שאלה,** עם "לא נפלתי" ו"כן, היה". אין בו שום מילה על בטיחות, פציעה או עזרה, והוא לא נכנס לתמונת השיתוף (`share_exclude`).
- **בלי עידוד למהירות** (מ-8, תנאי 9): אין "מהר יותר" או "נסו לשבור". המהירות היא עובדה שנרשמה ("רשום אצלך"), והשיאים מול עצמך בלבד ("מול עצמך בלבד, וניצחת").
- **בלי השוואה בין אנשים.** ההשוואה היחידה היא לגבהים, ממקור (`drop_refs` בקובץ הפרמטרים).
- **אוף-פיסט בטון רגוע:** בלי שבחים, בלי המלצה על קו, ובכל הטונים "הקו נשאר רק אצלך".
- **עברית בלי לשון זכר:** פנייה בעבר בגוף שני ("נשקת", "השתפרת"), שנכתבת אותו דבר לשני המינים, ו"שלך". **ברוסית** "вы", כך שגם העבר לא תלוי במין ("вы поцеловали"). **בגאורגית** גוף שני רבים.
- **המונחים מהמילון:** "ירידה", "רכבל", "מחוץ למסלולים", "יום גלישה" (`i18n/glossary.md`).

## מה עושים כשפיני בוחר

1. מעתיקים את הטון שנבחר ואת `shared` ל-`i18n/strings.json`. כל גרסה נכנסת כמפתח משלה (`<מפתח>.1`, `<מפתח>.2`), עם `check: ["ru", "ka"]` ו-`where` של האפליקציות. סדר הגרסאות לא משתנה, כי הוא קובע איזה נוסח `seed` בוחר.
2. מריצים את `python3 i18n/check.py` ואת כלי הבנייה של האתר והאפליקציה.
3. **אם פיני משנה נוסח, מעדכנים את כל ארבע השפות יחד.**

**לתיאום עם סשני האנדרואיד והאייפון** (ממליץ, לא מחליט): הדרך לספור את הגרסאות (מפתחות ממוספרים) והמיפוי של מפתחות המשנה. אם הם רוצים להעביר את מפתח המשנה מהמנוע עצמו, שם מקומו.
